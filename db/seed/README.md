# Seed de développement

Aucun produit n'est publié automatiquement.

Les produits du document Catalogue 2026 doivent être importés en statut `draft`, puis vérifiés par CTRL-TECH (référence, prix, devise, configuration, disponibilité, garantie et visuels). Seul un responsable autorisé pourra les passer en `published`.

Ne jamais utiliser de stock fictif dans l'environnement de production.
